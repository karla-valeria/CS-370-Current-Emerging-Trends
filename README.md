# CS 370 Project Two Reflection

For this project, I created a pirate intelligent agent that uses a deep Q-learning algorithm to find treasure in a game environment. The goal of the agent was to learn how to move through the map and reach the treasure before the player. I was given starter code that included the game environment, the pirate setup, and the basic structure needed for the agent. The provided code allowed the pirate to interact with the game world and provided the tools needed to train the agent.

The code I created was the Q-training algorithm for the pirate agent. I added the logic that allowed the pirate to learn from rewards and penalties. The agent learned which actions helped it get closer to the treasure and which actions did not. I also added comments to make the code easier to understand. After training, the pirate was able to make better decisions and successfully find the treasure.

Throughout this course, I learned that computer scientists use programming and algorithms to solve problems. They create software, build intelligent systems, and find ways to improve technology. This work matters because computer science helps solve real-world problems in areas like healthcare, business, and entertainment.

When I approach a problem as a computer scientist, I first need to understand the goal. I then break the problem into smaller steps and find the best way to solve it. For this project, I looked at how the pirate moved through the environment and used reinforcement learning to help the agent learn the best path to the treasure. Testing and improving the solution is also an important part of the process.

Computer scientists also have ethical responsibilities to users and organizations. They should create systems that are safe, reliable, and fair. When working with AI, developers need to think about how the system makes decisions and how it affects users. They should protect user information and make sure the technology is used responsibly.
